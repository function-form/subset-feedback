# Subset feedback

Bug reports and feedback for [Subset](https://subsetwp.com) plugins, including Pro betas.

[Open an issue](https://github.com/function-form/subset-feedback/issues/new/choose) and pick the form that fits:

- **Beta bug report**: something in a beta that's broken or wrong.
- **Beta feedback**: anything else about a beta, such as what's confusing, what's missing, or what works well.

Please don't post your licence key, passwords or anything else private: issues here are public. If a report needs private details, say so in the issue and we'll get in touch.

For billing or your account, use the [contact page](https://subsetwp.com/contact).
