# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

**[Report a vulnerability](https://github.com/function-form/subset-feedback/security/advisories/new)**

You need a GitHub account to use the form. Only the Subset team can see what you send.

This covers the Subset WordPress plugins (free and Pro), the Subset Installer and CLI, and subsetwp.com, including its licence and update API.

Please include:

- what's affected: the plugin and version, or the subsetwp.com page or API route
- the steps to reproduce it, and what an attacker gains
- whether it's already public anywhere

We'll reply within 3 working days, keep you updated while we fix it, and credit you in the release notes unless you'd rather we didn't.

Please don't test against sites you don't own, run automated scans against subsetwp.com, or access other customers' data.
